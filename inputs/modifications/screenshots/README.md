# 📸 Modification Screenshots Folder

Organize client visual feedback into these semantic subdirectories:

```text
inputs/modifications/screenshots/
├── ui_tweaks/       # Color, button, typography, alignment, spacing or padding changes
├── new_sections/    # Screenshots of brand new pages, cards, sections, or modals requested
└── bug_fixes/       # Screenshots highlighting visual bugs, overflow, or broken layout
```

The AI reads from these folders to ensure zero-placeholder, pixel-accurate implementation without guessing!
